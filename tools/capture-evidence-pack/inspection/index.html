Capture evidence pack inspection

Identity evidence for a bug report about one capture and one result. The local server runs tools/capture-evidence-pack/read.py on the pack and its referenced files for every page load, and this page shows only what that check returned. Served from localhost with no external network calls.

What this pack does not claim

  • No map of a real house. Every byte here is synthetic fixture data committed to this repository.
  • No installer approval. None is claimed, implied, or recorded.
  • No geometry-correctness assertion. The format requires geometry_correctness.assertion to be null, and the reader refuses any pack where it is not. Matching hashes say which bytes these are, not that their geometry is right. See SPEC.md, “Identity is not correctness”.
