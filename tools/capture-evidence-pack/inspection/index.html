Capture evidence pack inspection

Identity evidence for a bug report about one capture and one result. This page renders the committed pack tools/capture-evidence-pack/evidence/example.zip and its recorded receipts, served from localhost with no external network calls.

What this pack does not claim

  • No map of a real house. Every byte here is synthetic fixture data committed to this repository.
  • No installer approval. None is claimed, implied, or recorded.
  • No geometry-correctness assertion. The pack records identity only; geometry_correctness.assertion is null. See SPEC.md, “Identity is not correctness”.

Evidence unavailable

This page reads the pack through its local server. Run python tools/capture-evidence-pack/inspection/serve.py and open http://127.0.0.1:8793/.
